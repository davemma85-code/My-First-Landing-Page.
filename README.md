# Landing Page Project

This is my first responsive landing page built during my SIWES program at Chicago Digital Academy. 
I recreated it by coding the HTML structure and styling it with CSS.

## What I Learned
- HTML structure and semantic tags
- CSS Flexbox for layout
- CSS positioning, spacing, and responsiveness
- Using media queries for mobile devices
